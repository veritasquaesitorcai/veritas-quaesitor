The Resurrection Calculation

Hypothesis (H): Jesus of Nazareth physically rose from death, c. 30 CE. Method: Bayes' theorem in odds form. Every input below is stated, justified, and reproducible with the code at the end of this panel.

72–93% Posterior probability of H across four independently derived priors. 72% at the lowest prior; 52% under the stress test, which uses the skeptic's own figure for the most contested input.

Evidence: likelihood ratio per thread

Each ratio states how many times more likely the evidence is if H is true than if it is false. All are set conservatively.

  • E1Empty tomb4Early Jewish polemic disputed why the tomb was empty, never whether (Matthew 28:11-15). Rests on the multiply attested core, not the Matthew-only guard story.
  • E2Group appearances12Peter, the Twelve, 500+ at once (1 Corinthians 15:5-7). Grief visions conceded as common (0.6 under not-H); shared group experiences rare (0.1); 0.8 / 0.06 is about 13, we use 12.
  • E3Early creed21 Corinthians 15:3-7, dated 32-35 CE by critical scholars. Adds only the dating constraint; overlaps E2.
  • E4Sincerity under suffering3Witnesses endured persecution for their testimony. Rules out deliberate fabrication, not sincere error.
  • E5Paul5Persecutor turned witness, attested in his own letters.
  • E6James3Skeptical brother turned Jerusalem leader; earlier unbelief reported in Mark and John.
  • E7Novel belief3One man raised before the general resurrection, a claim Second Temple Judaism had no category for.

Raw product: 12,960. Divided by 5 for overlap between threads (E2, E3 and E4 partly measure the same facts). Effective likelihood ratio: 2,592.

Prior: four independent routes

  • 1. Symmetric singularity0.001Same rarity prior as other events lacking a demonstrated mechanism, such as abiogenesis.
  • 2. Agnostic split0.005P(God) = 0.5, times P(God raises this man | God) in the range 0.001 to 0.1.
  • 3. Peer reference class0.00330.5 × P(God vindicates a messianic figure in this era | God) of about 0.1, shared among ~15 known claimants.
  • 4. Skeptic's start0.0024P(God) = 0.1, updated on cosmic fine-tuning (likelihood ratio 2 to 10) to about 0.36, times the peer-class conditional 0.0067.

We use 0.001, the lowest of the four. Routes 2 to 4 do not depend on the abiogenesis comparison, and the Easter evidence is kept out of every prior so nothing is counted twice. For reference, the naturalistic default is 0.0000001.

Result

Prior odds       0.001 / 0.999     = 0.001001
Posterior odds   0.001001 × 2,592  = 2.59
P(H|E)           2.59 / 3.59       = 72%

Route 1: 72%   Route 4: 86%   Route 3: 90%   Route 2: 93%
Stress test (E2 cut to 5, lowest prior): 52%

An independent check on mechanism complexity (roughly 20× against composite naturalistic explanations) points the same way. It is not multiplied into the result, because the evidence ratios already reflect that no single alternative covers every thread.

Where to press

  1. Route 4's fine-tuning ratio (2 to 10). A multiverse advocate will push it toward 1. Our reply: an unobserved multiverse is itself a mechanism that must be argued for under the same standard.
  2. The group-appearance ratio (12). The strongest counter-precedent is collective Marian apparitions, which arose where people already expected the figure to appear. No one expected one man to be raised before the general resurrection (E7, used here as rebuttal only).
  3. The dependency discount (÷5). With no discount the result at the lowest prior is 93%; at ÷10 it is 56%.

Found a weaker input? Tell us, and we will publish the correction.

Run it yourself (Python) 
# The Symmetric Standard Model — runnable as written

def calculate_resurrection_probability(prior, likelihood_ratios, dependency_discount=5):
    """
    prior: probability before the Easter evidence (four routes published above)
    likelihood_ratios: one ratio per evidence thread (E1-E7)
    dependency_discount: correction for overlapping threads
    """
    odds = prior / (1 - prior)
    for ratio in likelihood_ratios:
        odds *= ratio
    odds /= dependency_discount
    return odds / (1 + odds)

ratios = [4, 12, 2, 3, 5, 3, 3]   # E1-E7

for prior in [0.001, 0.0024, 0.0033, 0.005]:
    print(prior, round(calculate_resurrection_probability(prior, ratios), 3))

How the key ratios were set

How the group-appearance ratio is derived (not asserted): we start from a concession. Grief experiences of the dead are common—roughly half of widowed people in Rees's 1971 study reported some experience of their spouse. So under no resurrection we grant a 0.6 chance of individual visionary experiences among the disciples. Shared experiences by groups, with common content, are rare: 0.1. That gives P(E|¬H) = 0.06 against P(E|H) = 0.8, a ratio of about 13. We use 12.

COHERENCE WEB ANALYSIS:

Critical insight: No single naturalistic explanation accounts for all evidence threads simultaneously.

Naturalistic Alternative Breakdown:

  • IF body stolen: Explains empty tomb → Does NOT explain 500+ witnesses
  • IF hallucination: Explains witnesses → Does NOT explain empty tomb (corpse remains)
  • IF legend development: Explains story → Does NOT explain 2-5 year creed (too fast)
  • IF conspiracy/fabrication: Explains claim → Does NOT explain martyrdom (knew it was false)
  • IF visionary experience: Explains Paul → Does NOT explain the empty tomb
  • IF social pressure: Does NOT explain James (skeptical family member, nothing to gain)

Early Creed Significance (1 Corinthians 15:3-8):

  • Dated 32-35 CE (2-5 years post-event) by critical scholars including Bart Ehrman
  • Paul received directly from Peter/James in Jerusalem (Galatians 1:18-19)
  • Lists falsifiable claims while eyewitnesses alive and reachable
  • Too early for legend (requires generations, not years)
  • Contains Aramaic features indicating Jerusalem origin

Bayesian Multiplication Effect:

Each thread adds support, and together they compound rather than add. Because some threads overlap (the creed, the appearances, and the witnesses' sincerity partly measure the same facts), we divide the combined ratio by 5 before applying it. Naturalistic explanations still have to account for all threads at once—no proposed alternative does so without several separate assumptions.

MECHANISM-AWARE COMPLEXITY PENALTIES:

Formalization: Composite explanations incur exponential coherence penalties.

Complexity Prior:

P(m|H) ∝ e^(-λ·Complexity(m))

Where:

  • k = number of independent causal mechanisms required
  • λ = parsimony coefficient (standard: λ=1, matching AIC/BIC model selection)
  • Complexity(m) = k + L_graph + θ (mechanism count + description length + parameters)

Application to Resurrection Evidence:

Naturalistic explanation requires:

  • Mechanism 1: Hallucination (for 500+ witness accounts)
  • Mechanism 2: Body theft (for empty tomb)
  • Mechanism 3: Legend formation (for early creed, despite 2-5 year constraint)
  • Mechanism 4: Conspiracy/deception (for disciple martyrdom testimony)

→ k = 4, Complexity penalty = e^(-4) ≈ 0.018

Resurrection explanation:

  • Single mechanism: Divine act of resurrection

→ k = 1, Complexity penalty = e^(-1) ≈ 0.368

Bayes Factor from mechanism complexity alone:

e^(4-1) = e^3 ≈ 20× factor against composite naturalistic explanations

This factor is an independent cross-check, not a multiplier. The per-thread ratios already reflect that no single alternative covers every thread, so multiplying the 20× factor in again would count the same point twice.

DAG Formalization (Objective Mechanism Counting):

Mechanisms are independent iff no directed causal path connects them in a Directed Acyclic Graph (DAG).

  • Naturalistic DAG: 4 disconnected subgraphs (hallucination path, theft path, legend path, conspiracy path) → k=4
  • Resurrection DAG: 1 connected subgraph (single causal event explaining all effects) → k=1

Symmetric Mechanism Requirement:

If naturalism demands demonstrated causal mechanisms for resurrection, same standard applies to:

  • Abiogenesis (life from non-life): No demonstrated mechanism after 70+ years of research
  • Universe origin (existence of laws): No mechanism for "why these laws and not others?"
  • Consciousness emergence: Hard problem remains unsolved, no physical mechanism demonstrated

Epistemic symmetry requires: Same mechanism standards, same complexity penalties, same prior treatment.

If naturalism receives epistemic grace for lacking mechanisms at origins, resurrection deserves equivalent treatment. If resurrection requires demonstrated mechanisms, naturalism's foundational claims require them equally.

Combined Effect:

We keep the 20× factor out of the result below. It stands as a second, separate method pointing in the same direction as the evidence-based calculation.

P(H|E) = P(E|H) × P(H) / [P(E|H) × P(H) + P(E|¬H) × P(¬H)]
