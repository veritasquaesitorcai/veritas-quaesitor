Connect your chat events

// Typing / request begins:
VQFace.setSpeaker('vq'); // or 'oria'
VQFace.setState('listening');
VQFace.setState('thinking');

// Start streaming an actual answer:
VQFace.beginResponse({speaker:'oria', cues:[
  {at:0, expression:'curious'},
  {at:70, expression:'warm'}
]});
VQFace.appendText(chunk); // each text delta
VQFace.endResponse();    // stream finished

// Or animate a complete response:
VQFace.respond({speaker:'vq', text:answer,
 cues:[{at:0, expression:'serious'}]});

// Optional audio mouth input:
VQFace.setMouth(0.6); // 0–1
VQFace.setMouth(null); // back to text
VQFace.pause(true);

Cue offsets count JavaScript string characters from the start of the response. Supply them from structured response metadata; they take priority over the conservative text-tone fallback. The demo scenes use explicit cues.

Existing vq-face page events accept speaker, state, expression, text and mouth. respond returns a Promise that completes after visual articulation.

Text mouth animation approximates speech. Audio amplitude improves opening timing; accurate lip-sync needs phoneme timing. This standalone file does not modify your live chat or connect to an AI service.
