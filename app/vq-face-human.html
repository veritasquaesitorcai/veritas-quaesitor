Character face engine

This prototype builds a shaded facial surface mathematically, projects it in 3D, and draws only monospace glyphs. It uses no images, videos, models, or network requests.

Continuous animation includes head rotation, saccades, eyelids, eye direction, breathing, brows and mouth. Expressions blend rather than jump.

Connect to VQ

Move the Face pane and its renderer into your existing tab system. Connect chat events using the public API:

VQFace.setState('thinking');
VQFace.setExpression('curious');
VQFace.setState('speaking');
VQFace.speakText('Your response text');
VQFace.setMouth(0.6); // audio amplitude, 0–1
VQFace.setState('idle');
VQFace.pause(true);

Or dispatch a page event:

window.dispatchEvent(new CustomEvent(
  'vq-face', {detail: {
    state: 'listening',
    expression: 'warm'
  }}
));

True lip-sync needs audio timing or phoneme cues. Text articulation here is a visual approximation. This file is a standalone integration prototype; your live app has not been modified.
