VQ · full body

Shoulders, elbows, wrists, fingers, hips, knees and ankles form a joint hierarchy. Movement eases between poses. Follow conversation maps thinking to a thoughtful pose and speaking to explaining gestures.

The walk cycle stays in place. This prototype has no navigation, obstacle avoidance or physics-based foot placement.

A physically inspired material renderer: metal roughness, brushed surface detail, Fresnel reflections, optical glass, and analytical studio-light reflections. The face remains clearly robotic.

All geometry and materials are procedural. No photographs, external textures or libraries are loaded. This is a real-time material prototype, rather than a scanned or offline-rendered production model.

Choose Studio, Warm room or Cool lab lighting, and turn the head to inspect reflections. Surface finish adjusts ceramic roughness. Chat integration and expression timing are unchanged.

Connect your chat events

// Typing / request begins:
VQFace.setSpeaker('vq'); 
VQFace.setAction('wave');
VQFace.setAction('auto'); // follow chat state
VQFace.setState('listening');
VQFace.setState('thinking');

// Start streaming an actual answer:
VQFace.beginResponse({speaker:'vq', cues:[
  {at:0, expression:'curious'},
  {at:70, expression:'warm'}
]});
VQFace.appendText(chunk); // each text delta
VQFace.endResponse();    // stream finished

// Or animate a complete response:
VQFace.respond({speaker:'vq', text:answer,
 cues:[{at:0, expression:'serious'}]});

// Optional audio mouth input:
VQFace.setMouth(0.6); // 0–1
VQFace.setMouth(null); // back to text
VQFace.pause(true);

Cue offsets count JavaScript string characters from the start of the response. Supply them from structured response metadata; they take priority over the conservative text-tone fallback. The demo scenes use explicit cues.

Existing vq-face page events accept speaker, state, expression, text and mouth. respond returns a Promise that completes after visual articulation.

Text mouth animation approximates speech. Audio amplitude improves opening timing; accurate lip-sync needs phoneme timing. This standalone file does not modify your live chat or connect to an AI service.
