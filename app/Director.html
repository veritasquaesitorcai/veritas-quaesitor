Server connection & API contract

New server contract for this app: POST JSON {"question":"…"}. Return JSON {"answer":"…","source":"clef"}. Errors: a non-2xx HTTP status with {"error":"…"}. Allow this page’s origin and the Content-Type, Authorization and X-VQ-Device headers in CORS. The endpoint above must be implemented on your server.

Only the current question is sent; earlier answers are not added as context. Tokens stay in memory and are never included in exports. No requests run automatically.
